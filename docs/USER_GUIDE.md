# myworld 使用手册

独立 Windows 工具：两栏同步阅读、批注与添加文本，工作副本支持擦除；新增与 PDF 关联的图文笔记。PDF、密码和笔记都在本机处理。

## 拖放打开 PDF

把本地 PDF 拖到任一 PDF 栏、侧栏或笔记区域即可打开。窗口未打开文档时也支持。只接收实际存在的本地 PDF，不自动下载网页链接；同时拖入多个 PDF 时打开第一个。切换沿用原有工作记录保存与校验流程。

## 将工作副本保存成其他阅读器可打开的 PDF

点击工作副本标题旁“保存为 PDF…”，或顶部“导出副本 PDF”（Ctrl+E），选择新文件名。程序先提交正在输入的文字与评论，并尝试保存工作记录，再生成标准 PDF。原稿和工作副本的当前修改都会进入结果，擦除会实际移除内容，原始 PDF 保留。

导出成品可直接用福昕等阅读器查看和批注，无需运行 myworld。图文笔记和分层撤销历史留在 .pdfwork 中；导出 PDF 不是工作记录的替代品。记录保存失败不会阻止 PDF 导出，但会提示“记录另存为”。

## 启动与升级

1. 完整解压到**新文件夹**，不要直接在压缩包内运行，也不要覆盖正在运行的旧版本。
2. 双击 `Start_myworld.bat`。无需另装 Python、福昕，也无需联网下载依赖。
3. 打开 PDF，或把 PDF 拖入窗口。可先使用包内 `demo.pdf`。
4. 升级前请备份旧 `.pdfwork`。myworld 0.6.2 可以读取 0.2 的 JSON 记录、0.3 的压缩记录和 0.4 的图文记录；旧的单篇笔记自动成为第一篇笔记。保存后采用新格式，旧程序不能读取新格式。

适用：Windows 10/11 **x64**。移动应用时复制整个文件夹，保留 `runtime` 及所有 Python 源文件。出错时运行 `Diagnostic.bat`；未处理异常记录到本目录 `myworld_error.log`。

## 主要交互：可调图片与常驻批注

- **笔记图片**：点击选中图片，拖动右下角调整大小，或输入宽度（40–3200 px）；保持宽高比，也可选择“适合笔记”或“原尺寸”。显示尺寸随笔记保存，Ctrl+Z 撤销；缩放不会重复存储原始图片。
- **按需显示文字属性**：只有启用“添加文本”、编辑文本框或选中新增文本时，才显示字体、字号及文字编辑控件。选中已有新增文本后更改字体/字号会进入该文本框编辑。
- **笔记按钮分组**：“截图到笔记”“摘录到笔记”“笔记”在同一行相邻排列；F8 和 Ctrl+Shift+N 快捷键保留。
- **常驻评论**：选中文本并创建高亮、下划线或删除线后，点击小栏“评论”。点击卡片继续输入，停止输入约 0.9 秒或点击别处保存；未编辑卡片为半透明，编辑时不透明。拖动标题移动，位置随工作记录保存。
- **同色指向**：卡片边框、标题颜色与标注相同，悬停时以同色连线及轮廓指向对应文字。页面离开可见区域时释放卡片，回来后恢复，避免长文档积累窗口。常驻是阅读界面的显示行为，导出 PDF 使用标准批注内容；其他阅读器如何显示弹窗由其自身决定。
- **原稿与副本**：两栏均可评论。原稿评论可“保存原稿”写回 PDF；副本评论随工作记录及导出副本保存。移动卡片不修改 PDF 内容。

## 就地操作与笔记选择

- **选中文字的小栏**：在选区附近显示复制、高亮、下划线、删除线和“记笔记 ▾”；顶部工具栏同时保留这些操作。
- **批注的小栏**：点中高亮、划线等批注，或用小栏创建批注后，会切换为评论、颜色和删除。点击“评论”打开常驻卡片，输入后自动保存，并写入导出的标准 PDF 批注。
- **颜色下拉面板**：常用色块加 #RRGGBB 输入就地弹出，不再调用独立的系统颜色对话框。可以修改当前批注，也可以调整画笔或正在输入的文字颜色。
- **目标笔记列表**：点“记笔记 ▾”，选择已有命名笔记，或新建后直接插入。每次摘录都会在目标笔记末尾另起一行，并保留原文页码。
- **多篇笔记**：每份 PDF 最多 100 篇笔记；右侧可切换、新建，编辑笔记名称后按 Enter 重命名。不同笔记的正文、截图一起存进该 PDF 的工作记录。
- **直接粘贴截图**：自己用系统截图工具截图后，在笔记中 Ctrl+V 即可；图片单独占一行，前后文字保持分段。程序内的 S 截图功能仍可选用。
- **清晰的插入光标**：文本框直接绘制深色闪烁光标，并随键盘、鼠标和输入法位置更新，不依赖嵌入控件的默认光标；选颜色后恢复输入焦点。
- **更明显的交换入口**：两栏标题处都有“⇄ 交换两栏”，顶部还有“交换原稿 / 副本”和 Ctrl+Shift+X；交换只改变位置，原稿与工作副本身份保持不变。顺序会保存到工作记录。

## 添加文字：在页面内输入

参考常见 PDF 编辑器的页面操作方式：

1. 按 **T**，点击页面放置文本框，或拖出所需区域，直接输入文字。
2. 在顶部工具栏选择字体、字号和颜色，文字即时更新。同一文本框采用统一格式。
3. **拖动边框移动文本框**，**拖动右下角调整宽高**；输入时高度会在页内尽量自动扩展。
4. 按 **Ctrl+Enter** 或点“完成输入”，也可切换工具完成；**Esc** 取消当前编辑。
5. 在选择模式双击新增文字，或选中后点“编辑文本”，即可再次输入。文本工具点击已有的工作层文本也会进入编辑。

文本框内的 Ctrl+Z 撤销文字输入或格式调整；退出输入框后，Ctrl+Z 撤销 PDF 编辑操作。支持 Qt 原生中文输入流程，字号 4–144 pt。输入框空间不足时阻止完成，避免静默丢字；导出阶段也会再次检查排版空间。

支持本机已经安装的微软雅黑、黑体、宋体、仿宋、楷体、Arial、Times New Roman、Courier New；另有内置中文字体。程序不捆绑或下载 Windows 字体。打开别的电脑的工作记录时，如果缺少所用字体，导出会提示更换可用字体。

本功能用于添加文字，不提供原 PDF 任意段落的重排编辑。工作层文本可继续修改；一旦写入原稿或导出为 PDF，新文字成为页面内容，需保留工作记录才能继续以文本框编辑工作副本。

## 高亮

高亮采用标准 PDF 高亮所用的乘色混合方式：背景呈现高亮底色，**黑字保持黑色**，不会像普通半透明颜色覆盖一样变浅。界面和导出使用一致的混合规则；本版已用像素检查验证黑字颜色保持不变。

高亮、下划线和删除线按 PDF 文字的字符与行定位；扫描页无文字层时，可以拖出区域标注。扫描页不提供 OCR。

## PDF 与工作记录自动关联

默认记录在 PDF 旁边，例如：

- `课程.pdf`
- `课程.pdfwork`

打开 PDF 时会优先查找之前登记的位置，然后查找同文件夹的同名记录，也兼容 `课程.pdf.pdfwork`。只有 **SHA256 内容校验和页数匹配**才加载，随后恢复批注、擦除、补充文字、图文笔记和已保存的阅读位置。

已完成的 PDF 编辑和笔记变更会在闲置约 2 秒后自动保存；Ctrl+S 可立即保存。**正在输入的文本框须先完成输入**，才成为工作记录中的 PDF 操作；Ctrl+S 会先完成输入再保存。

文件夹不可写、记录不匹配或保存失败时，状态栏会提示，不会静默覆盖不匹配记录。使用 **文件 → 记录另存为（Ctrl+Shift+S）** 选择可写位置；程序记住该 PDF 与自定义记录路径的关联。读取旧记录或搬迁时，也可用“打开记录”手动定位。

请把 PDF 与 `.pdfwork` 一起保留。记录不包含原 PDF，也不包含字体文件。笔记截图存入记录内部，无需另带图片目录。

## 侧栏图文笔记

- **F8 / “笔记”**：显示或隐藏右侧笔记栏，每份 PDF 有自己的命名笔记列表。
- **摘录文字**：在任一 PDF 栏选择文字，点“摘录到笔记”，按 **Ctrl+Shift+N**，或右键选择同名命令。
- **来源回跳**：摘录附有“第几页 / 原稿或工作副本”来源；点击页码可同步跳回对应区域。
- **页面截图**：按 **S / “截图到笔记”**，在 PDF 页面拖出区域；截图和来源一起插入笔记。
- **外部截图 / 图片**：在笔记中直接 Ctrl+V 粘贴剪贴板图片，或点“插入图片”选择 PNG、JPEG、BMP。
- **书写整理**：直接输入，支持加粗、斜体、下划线、标题、正文和项目符号列表。笔记里的 Ctrl+Z 只撤销笔记编辑。
- **导出笔记**：生成包含图片的独立 HTML 文件，适合备份和分享；来源页码链接指向本机 PDF，接收方需自行定位对应原稿。

PDF 截图按当前显示比例捕获可见选区，包含当前栏已经显示的批注和补充内容。复杂擦除会先白色即时反馈，再由后台更新真实结果；请等预览更新后再截取最终效果。

为控制存档大小，图片最长边限制为 1600 像素；相同图片按内容去重，删除的图片不再写入下一次存档。单份记录的图片总量上限 16 MB、最多 400 张。笔记只保存当前内容，文字输入的逐字撤销历史不跨关闭恢复，切换笔记也会重置该编辑器的逐字撤销历史；PDF 工作层的撤销/重做历史仍会恢复。

这是本地阅读笔记功能，借鉴边读边摘录的操作流程。

## 两栏和三种保存

原稿栏与工作副本都支持高亮、下划线、删除线、画笔和添加文本。原稿新增批注也会显示到工作副本；工作副本的新增编辑不会反向出现在原稿。只有工作副本可擦除。两栏共享页码、连续滚动位置、缩放、旋转，可左右交换。

| 保存方式 | 作用 |
| --- | --- |
| 自动保存 / Ctrl+S | 保存 `.pdfwork`：两栏尚未写回的 PDF 编辑、工作副本历史、已写回原稿的操作记录、笔记、截图与阅读位置 |
| Ctrl+Alt+S / 保存原稿 | 只把原稿栏的修改写回原始 PDF，工作副本擦除不会写进去；保留一份滚动备份 `原文件.pdf.studypdf.bak` |
| Ctrl+E / 导出副本 PDF | 另存两栏编辑的最终结果，实际移除工作副本擦除区域的内容，再写入补充文字；笔记通过“导出笔记”单独导出 |

**保存原稿后，已写回的原稿操作退出可撤销历史**；工作副本历史保留。原稿批注仍可选择删除，写回的新增文本成为页面文字。原稿保存保留加密、书签和附件，可能使签名失效。

导出时，高亮、下划线、删除线、画笔保留为标准 PDF 批注；新增文字嵌入所用字体，并尽可能子集化。擦除实际移除区域内容，复杂矢量对象与区域相交时可能整体移除；相交批注或新增文本框也可能整体移除。先擦除再添加的补充文本会保留。

导出副本会清理附件、脚本、缩略图和元数据，完整重写并回收垃圾，不加密；签名可能失效。区域擦除不等于全文件敏感信息扫描，其他页面和未处理内容仍需核对。原稿被外部程序改动后，保存原稿和导出会停止，工作记录不会自动错位套用。

搜索范围是原稿文件的文字，不包含尚未写入原稿的新增文字，最多 2000 个结果。工作副本复制会过滤原文字的擦除区域；新增工作层文本可进入输入框后选择复制。文本框统一格式，不支持同一框内混合多套字体。

## 验证与性能范围

95 项自动测试在 **Linux Qt 离屏环境**通过。新增验证包括图片等比例拖动、宽度调整与撤销、尺寸存档恢复且图片不重复存储，字体属性按需显示，常驻评论的焦点透明度与悬停指向，评论跨翻页、撤销/重做、原稿保存与重新打开，卡片位置在缩放和交换后保持，以及导出前刷新最新评论。原有文本输入、高亮像素、PDF 导出与记录关联等回归检查均保留。界面已做图像检查。

本次 800 页模拟文档基准（首页含密集文字与 1200 个矢量元素）：连续 120 次批注单次中位 10.69 ms，P95 19.47 ms，最大 24.13 ms，额外页面重绘 0 次；对应记录约 3 KB。初始化约 244 ms，两栏首页就绪约 997 ms；后台擦除时界面心跳最大间隔约 22 ms。该数据来自 Linux 模拟文档，不代表你的真实书籍和 Windows 电脑的保证值。

**尚未在 Windows 实机运行，也没有拿到你的真实《动手学深度学习》PDF 复测。** Windows 包验证了官方依赖哈希、x64 架构、本机库依赖闭包及 JPEG 插件，静态检查不等于 Windows 实机验证。Qt 中文输入提交测试也不等于在所有 Windows 输入法实机验证。
