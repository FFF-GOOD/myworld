# myworld v0.6.1 · 首个公开预览版

myworld 是本地双栏 PDF 阅读、标注、擦除与图文笔记工具，前身为 StudyPDF。本版完成公开名称变更和开源资料整理；保留已有 .pdfwork 格式，不升级 PDF/Qt 引擎。

## 下载

在本页 Assets 下载 **myworld_0.6.1_Windows_x64.zip**，完整解压后双击 **Start_myworld.bat**。支持 Windows 10/11 x64，无需安装 Python。不要只下载自动生成的 Source code ZIP 来直接运行。

## 功能

- 原稿与副本同步页码、滚动、缩放、旋转，支持左右交换。
- 两栏高亮、下划线、删除线、画笔和页内添加文本；文字可设置本机可用字体、字号与颜色。
- 副本矩形或画笔擦除，支持撤销与重做；导出新 PDF 实际移除区域内容。
- 同色常驻评论：半透明、点击编辑、拖动、悬停指向原文。
- 多篇图文笔记、选文摘录、页面截图、Ctrl+V 图片粘贴和等比例缩放。
- PDF 对应 .pdfwork 自动加载；原稿修改可单独保存。

## 升级与验证

解压到新文件夹，不覆盖正在运行的旧版本。先备份 PDF 和 .pdfwork。内部历史标识保留，因此旧记录无需批量替换或转换。

95 项既有回归运行加 4 项品牌/兼容性检查在 Linux Qt 离屏环境通过；尚未在 Windows 实机系统性验证。CI 配置已提供，线上运行结果以仓库 Actions 为准。建议先用 demo.pdf 体验，本版标记为公开预览。

复杂矢量对象与擦除区域相交时可能被整体移除；导出前核对效果。无 OCR、任意原正文重排或电子签名功能。
